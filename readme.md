
# Portfólio Profissional

Este é um projeto de portfólio front-end desenvolvido com foco em apresentação profissional, design dinâmico e usabilidade. O objetivo principal é demonstrar competências práticas na construção de uma interface web interativa, acessível e bem estruturada.

## Estrutura e Organização
* **Arquitetura:** Separação estrita de responsabilidades entre estrutura (`index.html`) e estilo (`style.css`).
* **Hospedagem de Ativos:** Imagens servidas via links diretos em nuvem, mantendo o repositório local leve e otimizado.

## Atendimento aos Critérios de Avaliação

* **Corretude Técnica e Web Standards:** 
  * Utilização de HTML5 semântico (tags como `<header>`, `<section>`, `<footer>`).
  * CSS3 moderno com aplicação de *Reset* básico, variáveis e organização modular.
  * Estruturação de layout utilizando *Flexbox* para alinhamentos flexíveis e precisos.
* **Qualidade Visual e Usabilidade da Interface:** 
  * Implementação do efeito **Parallax** no cabeçalho e rodapé, criando profundidade imersiva.
  * Carrossel de projetos interativo utilizando `scroll-snap`, proporcionando uma navegação magnética, suave e intuitiva através de setas de controle direcional.
  * Esquema de cores e contrastes pensados para facilitar a leitura.
* **Responsividade:** Layout totalmente adaptável a dispositivos móveis (smartphones e tablets) através do uso rigoroso de *Media Queries*.
* **Acessibilidade:** Implementação de `prefers-reduced-motion` no CSS, garantindo que usuários com sensibilidade visual tenham uma experiência segura, desativando automaticamente rolagens e efeitos estéticos de movimento.
